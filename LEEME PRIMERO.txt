El .3dsx queda disponible para Homebrew Launcher.
No mezclar Image y ejecutable de versiones diferentes.

Es Linux RISC-V emulado dentro de homebrew, no un kernel ARM
nativo nuevo ni un reemplazo del sistema Nintendo. La primera
vez extrae rootfs.ext2 en la SD; el proyecto indica unos 200 MB
para el sistema y 64 MB de swap. Hay que revisar espacio libre.
No cambiar boot.firm ni instalar nada en las particiones FIRM.

El proyecto incluye herramientas de red y Dropbear. Su red actual
permite conexiones salientes, pero no acceso SSH entrante directo.
Por ello esta descarga no deja la consola lista para administrarla
desde el PC: hay que preparar y probar ese acceso por separado.
La documentacion original usa root sin clave al inicio; antes de
habilitar acceso remoto configuraremos autenticacion.

El ZIP original, comprobado, esta en descargas.
procedencia.json registra origen, version y SHA256. Los archivos
para 3DS se extrajeron y verificaron sin ejecutar el programa.
